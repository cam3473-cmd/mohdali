# نظام عضوية الجمعية العمومية — جمعية البر الخيرية بمحافظة السليل

نظام مكتبي محلي (يعمل بدون إنترنت) لإدارة عضوية الجمعية العمومية، مبني بلغة Python
باستخدام PySide6 (Qt) وقاعدة بيانات SQLite محلية. يدعم تعدد المستخدمين على نفس الجهاز
عبر تسجيل دخول بصلاحيات، ويغطي:

- إدارة الأعضاء (طلبات العضوية، القبول/الرفض، الاشتراكات، بيانات ديموغرافية: المؤهل
  العلمي، المدينة، العمل).
- إدارة اجتماعات الجمعية العمومية: جدول الأعمال، الأهلية التلقائية (بحساب دقيق بالأيام)،
  النصاب، الحضور (شخصي/بالتوكيل)، التصويت على القرارات، وطباعة المحضر وكشف الدعوة بصيغة
  PDF بدعم كامل للغة العربية.
- سجل مناصب مجلس الإدارة (رئيس، نائب، أمين صندوق...) بتاريخ التعيين والانتهاء.
- استيراد الأعضاء دفعة واحدة من ملف Excel (يتعامل تلقائيًا مع التواريخ الهجرية/الميلادية
  المختلطة الشائعة في سجلات الجمعيات الأهلية).
- إعدادات قابلة للتهيئة للائحة الأساسية (مدة العضوية بالأيام، النصاب، الأغلبية، فئات
  العضوية المصوّتة) بدلاً من تثبيتها في الكود، لأنها تختلف من جمعية لأخرى ويجب أن تُضبط
  وفق اللائحة الأساسية المعتمدة رسميًا من [المركز الوطني لتنمية القطاع غير الربحي](https://ncnp.gov.sa).

> **تنبيه مهم:** القيم الافتراضية للنصاب والأغلبية ومدة العضوية (في شاشة الإعدادات) هي
> قيم استرشادية فقط. راجعها وعدّلها من شاشة "الإعدادات ← اللائحة الأساسية" لتطابق اللائحة
> الأساسية المعتمدة فعليًا لجمعيتكم قبل استخدام النظام في اجتماع رسمي.

## المتطلبات

- Python 3.11 أو أحدث.
- نظام تشغيل ويندوز (الاستخدام الأساسي)، ويعمل أيضًا على macOS/Linux.

## التشغيل من الكود المصدري (للتطوير)

```bash
python -m venv .venv
# ويندوز:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
python -m app.main
```

عند أول تشغيل يتم إنشاء قاعدة بيانات محلية تلقائيًا وحساب مدير افتراضي:

- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

سيُطلب تغيير كلمة المرور فور أول تسجيل دخول (إجباري).

### مكان قاعدة البيانات

- ويندوز: `%APPDATA%\JamiyatAlBirrSulail\membership.db`
- macOS: `~/Library/Application Support/JamiyatAlBirrSulail/membership.db`
- Linux: `~/.local/share/JamiyatAlBirrSulail/membership.db`

يمكن تغيير المسار عبر متغير البيئة `MOHDALI_DATA_DIR`.

## تشغيل الاختبارات

```bash
pip install -r requirements.txt
python -m pytest tests/ -q
```

تشمل الاختبارات: منطق الأهلية والنصاب والأغلبية والاستيراد (`tests/test_*_service.py`)،
وفحص دخان لإقلاع جميع شاشات الواجهة (`tests/test_ui_smoke.py`) عبر `QT_QPA_PLATFORM=offscreen`.

## بناء نسخة تنفيذية مستقلة (.exe لويندوز)

يُنفَّذ هذا الأمر على جهاز ويندوز نفسه (PyInstaller لا يدعم البناء التبادلي بين الأنظمة):

```powershell
pip install -r requirements.txt
pyinstaller packaging\app.spec
```

الناتج في `dist\نظام-عضوية-الجمعية\` — انسخ هذا المجلد بالكامل إلى جهاز الجمعية وشغّل
الملف التنفيذي منه مباشرة (لا يحتاج تثبيت Python).

## استيراد الأعضاء من Excel

من شاشة "الأعضاء ← استيراد من Excel" يمكن تحميل ملف `.xlsx` دفعة واحدة. يتعرّف النظام على
الأعمدة تلقائيًا من عناوينها (الاسم، رقم عضوية، تاريخ بدء العضوية، نوع العضوية، المنصب
الحالي، حالة السداد، قيمة الاشتراك، فعال، رقم السند/القيد، السجل، تاريخ الميلاد، الجوال،
الجنس، المؤهل، المدينة، العمل) بصرف النظر عن ترتيبها، ويحوّل تلقائيًا:

- السنوات الهجرية القديمة (≤ 1500) في تاريخ الانضمام/الميلاد إلى ميلادي تقريبي.
- التواريخ الهجرية الكاملة بصيغة `يوم/شهر/سنة` أو `سنة/شهر/يوم`.
- رمز "فعال" الشائع في ملفات إكسل (حروف Wingdings مثل þ/ý) إلى حالة عضوية نشط/موقوف.

بعد الاستيراد يعرض النظام تقريرًا بعدد الأعضاء الجدد/المحدَّثين وأي تنبيهات (مثل أنواع
عضوية مستوردة غير مدرجة ضمن "أنواع العضوية المصوّتة" في الإعدادات).

## النسخ الاحتياطي

من شاشة "الإعدادات ← النسخ الاحتياطي" يمكن تصدير نسخة من ملف قاعدة البيانات أو استعادة
نسخة سابقة. يُنصح بأخذ نسخة احتياطية دورية (أسبوعيًا على الأقل) وحفظها في مكان آمن منفصل
عن جهاز الجمعية.

## هيكل المشروع

```
app/
  main.py            نقطة التشغيل
  db/                نماذج قاعدة البيانات والاتصال بها
  auth/               المصادقة والصلاحيات
  services/            منطق الأعمال (العضوية، الأهلية، الجمعية العمومية، مجلس الإدارة، الاستيراد، الإعدادات)
  ui/                  شاشات PySide6
  reports/              توليد ملفات PDF (محضر الاجتماع، كشف الدعوة)
  resources/fonts/       خط Amiri العربي (رخصة SIL OFL) المستخدم في تقارير PDF
tests/                  اختبارات pytest (منطق الأعمال + فحص دخان للواجهة)
packaging/app.spec      ملف تغليف PyInstaller
```

الأساسية المعتمدة.
