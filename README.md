# نظام إدارة بيانات المستفيدين والدعوم

نظام لجمعية البر الخيرية بمحافظة السليل لإدارة بيانات المستفيدين من خدمات الجمعية،
وتسجيل الدعوم المقدمة لهم سنوياً (دعم نقدي، دعم عيني، دورات تدريبية وتأهيلية)، مع إمكانية
تصدير تقارير Excel لرفعها لصندوق دعم الجمعيات والمركز الوطني لتنمية القطاع غير الربحي ومنصة إحسان.

## طريقة العمل

يعمل النظام كـ **تطبيق سطح مكتب** يُثبَّت على جهاز واحد في الجمعية (يُستخدم كخادم)، ويشتمل
داخلياً على خادم محلي (Express + قاعدة بيانات SQLite). بقية الموظفين (حتى 5 موظفين بصلاحيات
كاملة متساوية) يمكنهم الدخول للنظام من أجهزتهم عبر متصفح الإنترنت باستخدام عنوان الشبكة
الداخلية الذي تعرضه شاشة تسجيل الدخول (مثال: `http://192.168.1.10:4000`)، دون الحاجة لأي
اتصال بالإنترنت أو استضافة سحابية.

## هيكل المشروع

- `server/` — الخادم الخلفي (Node.js + Express + TypeScript + Prisma + SQLite)
- `web/` — واجهة المستخدم (React + TypeScript + Vite)، تدعم الاتجاه من اليمين لليسار
- `electron/` — غلاف تطبيق سطح المكتب الذي يشغّل الخادم والواجهة معاً في تطبيق واحد

## البيانات والوحدات

- **المستفيدون**: البيانات الأساسية، الحالة الاجتماعية، الدخل، الحي، تصنيف الاحتياج، حالة الملف
- **الدعم النقدي**: المبلغ، النوع (شهري/طارئ/موسمي)، تاريخ الصرف، السنة المالية
- **الدعم العيني**: التصنيف (مواد غذائية/ملابس/أثاث/أجهزة/طبي/مدرسي)، الوصف، الكمية، القيمة التقديرية
- **الدورات التدريبية**: حاسب آلي، لغات، ذكاء اصطناعي، مهارات حياتية — مع تسجيل المستفيدين وحالة إكمالهم وإصدار الشهادات
- **التقارير**: تصدير Excel للمستفيدين، الدعم النقدي، الدعم العيني، الدورات، وتقرير سنوي شامل

## التشغيل في وضع التطوير

يتطلب Node.js 18 أو أحدث.

```bash
# تثبيت جميع الاعتماديات (الجذر + server + web)
npm install

# إعداد قاعدة البيانات (ينشئ قاعدة SQLite ويطبّق المخطط)
cd server
cp .env.example .env
npm run db:migrate
npm run db:seed   # ينشئ حسابات الموظفين الافتراضية

# تشغيل الخادم (من مجلد server)
npm run dev

# في نافذة طرفية أخرى: تشغيل واجهة الويب (من مجلد web)
npm run dev
```

ثم افتح `http://localhost:5173` في المتصفح.

## بناء تطبيق سطح المكتب (Electron)

```bash
npm run build          # يبني واجهة الويب والخادم
npm run electron        # يشغّل تطبيق سطح المكتب محلياً للاختبار
npm run dist             # يبني حزمة تثبيت (Windows / macOS / Linux) عبر electron-builder
```

عند أول تشغيل للنسخة المُجمَّعة (dist) على جهاز جديد، يقوم التطبيق تلقائياً بإنشاء قاعدة
بيانات جديدة في مجلد بيانات المستخدم وتطبيق حسابات الموظفين الافتراضية.

## تصدير التقارير

من شاشة "التقارير" يمكن تحميل:
- تقرير المستفيدين
- تقرير الدعم النقدي (حسب السنة)
- تقرير الدعم العيني (حسب السنة)
- تقرير الدورات التدريبية والمسجلين بها
- **التقرير السنوي الشامل** — ملخص وتفاصيل الدعم النقدي والعيني لسنة محددة، معدّ ليكون
  الأساس لتعبئة نماذج صندوق دعم الجمعيات والمركز الوطني لتنمية القطاع غير الربحي ومنصة إحسان.

> ملاحظة: أعمدة التقارير الحالية تغطي البيانات الأساسية المطلوبة عادة من هذه الجهات. عند
> توفر النموذج الرسمي الدقيق (Excel Template) من أي منها، يمكن تعديل ملف
> `server/src/routes/reports.ts` بسهولة لمطابقة أسماء وترتيب الأعمدة المطلوبة تماماً.

## الأمان والنسخ الاحتياطي

- قاعدة البيانات ملف SQLite واحد (`data.db`) — يُنصح بعمل نسخة احتياطية دورية له (نسخه إلى
  محرك تخزين خارجي أو USB بشكل أسبوعي على الأقل).
- كل عملية إدخال بيانات (مستفيد، دعم نقدي، دعم عيني، تسجيل بدورة) تُسجَّل باسم الموظف الذي
  أدخلها، للمساءلة والتدقيق.
